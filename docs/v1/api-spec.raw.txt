WebSocket protocol and error codes
Live channel
Students and admins connect to wss://<host>/api/v1/ws/live . The first message must
be the token, sent in the message body rather than the URL so it does not appear in
server logs; the server closes the socket if it is missing within 5 seconds.
The socket carries no history. After any reconnect the client calls GET /buses/live
before resuming, as in the TRD.

Driver route assignments (V1.3)

GET /routes/assigned is driver-only and returns the active routes assigned to the caller.
POST /trips/start accepts only an assigned route; when route_id is omitted, the linked bus
default route is used and must also be assigned. An unassigned, draft or inactive route returns
400 VALIDATION_ERROR.

Admins manage assignments through GET /admin/drivers/{id}/routes and PUT
/admin/drivers/{id}/routes with { "route_ids": [UUID, ...] }. PUT replaces the complete
allow-list and accepts only active routes.
