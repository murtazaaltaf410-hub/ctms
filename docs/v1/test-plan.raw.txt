Most checks are automated on the server and a GPS simulator, because they are cheap to
repeat; real-bus checks are reserved for what only a phone on a road can prove. Test IDs
link back to the Edge Case Catalogue and the PRD.
Test strategy and environments
Environments: local (developer machine), staging (separate free-tier server and
database with test Google keys), and production for the pilot. Staging is where the
simulator and the first field test run.

Pilot acceptance and exit criteria
The pilot starts only when every launch item passes, and it is judged a success against the
PRD's success metrics after two weeks of use.
Launch gate (all must pass)
Pilot success (after two weeks)
When a metric misses, record the cause (hardware, network, algorithm or adoption) and
the fix before widening the pilot.
